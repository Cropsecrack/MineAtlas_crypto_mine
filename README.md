MINEATLAS — PROJECT README:
==========================

MineAtlas is a single-file, dark-mode mining hardware and self-custody command center for comparing ASICs, home solo miners, hardware wallets, and site power infrastructure...

1. MULTI-TAB WORKSPACE
----------------------
- Overview (#/overview): Interactive particle/laser hero, quick-launch stat cards, and FAQ.
- Directory (#/directory): 18 systems across Antminers, Home & Other Miners, Air-Gapped Wallets, Touch & NFC Wallets, and Infrastructure with search, sorting, and Grid/Table views.
- Blueprints (#/blueprints): Setup architectures for Home Solo, Garage Multi-Rig, Hydro/Industrial, and Air-Gapped Multisig.
- Fleet Calculator (#/calculator): Multi-unit wattage, electricity rate, and PUE cooling overhead modeler with a live Chart.js breakdown.
- Facility Sim (#/facility): Interactive airflow and telemetry zone walkthrough (Hot Aisle, Hydro Loop, PDU Vault, Signing Room).

2. INTERACTIVE TOOLS
--------------------
- NASA 3D Telemetry Inspector: Click any product card to orbit its photo inside a Three.js wireframe cage with live yaw/pitch coordinates, wireframe, and explode toggles.
- Comparison Matrix: Select up to 3 systems to compare specs and daily electricity costs side-by-side.
- MineAtlas Advisor: Built-in semantic catalog and live kWh math assistant, with an optional settings toggle to connect your own Gemini API key.

3. HOW TO RUN
-------------
Open mineatlas.html in any modern browser. No build step or backend server is required. All electricity calculations are estimates only and do not predict mining profitability.
